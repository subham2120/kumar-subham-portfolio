# Kumar Subham — Personal Developer Portfolio

A responsive, animated personal job portfolio built with React + Vite.

## Run locally
1. Install Node.js LTS.
2. Extract this project and open the folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by Vite.
